# Paper Filter Booth 자재체크

Paper Filter Booth 부품 목록(참고 / Reference 22–23쪽, NC 1–63)을 현장에서 체크하는 웹 앱.

- 부품 63건 검색·필터(전체/미확인/일부/완료/PART/PURCHASE/SET)
- 수량 +/−, 메모 입력, 진행률 표시
- 부족분 내보내기(SET 제외), 초기화
- 체크 상태는 브라우저 localStorage에 저장됨

## 실행

GitHub Pages: https://uhehehe-sea.github.io/paper-filter-booth-check/

로컬: `index.html`을 브라우저로 열면 된다.
